# Android TV Customizer Studio

A Windows app that customizes Android TV and Google TV sets over ADB: guided connection, safe and
reversible debloating, a visual theme studio, an optional lightweight launcher, one-click deployment
with verification, and exact rollback. No app needs to be installed on the TV unless you choose the
custom launcher.

Status: **M9 (simulated half)** done: 145 core tests, 39 UI tests and 13 end-to-end scenarios on a simulated TCL Google TV. Real-TV validation is pending: see [docs/TESTING.md](docs/TESTING.md). See [docs/PLAN.md](docs/PLAN.md) and [docs/TASKS.md](docs/TASKS.md).

## Layout

| Path | What |
|---|---|
| `src/` | React + TypeScript (strict) + Tailwind UI |
| `src-tauri/` | Tauri 2 app crate: thin command layer |
| `crates/tvs-core` | Validated identifiers (package, component, serial) |
| `crates/tvs-transport` | ADB transport trait, adb.exe driver, scriptable mock TV |
| `crates/tvs-safety` | Hard safety rules (core packages, factory packages, launcher checks) |
| `crates/tvs-device` | Endpoint parsing, TCP diagnostics, capability probe, OEM families, package inventory, guard facts |
| `crates/tvs-kb` | Package evidence from 316 tested TVs (built by `tools/build_kb.py`) |
| `crates/tvs-recovery` | Baseline snapshots, verified batch disabling, exact restore |
| `crates/tvs-launcher` | Theme schema/validation, wallpaper intake, theme delivery, launcher install / Home handover / uninstall, revert step |
| `launcher/` | The Studio launcher (Android, Java): fork of CleanYourTV's launcher, see `launcher/NOTICE.md` |
| `schema/theme.v1.json` | Theme keys, types and defaults (generated by `tools/build_theme_schema.py`) |
| `public/themes/` | Original theme wallpapers (generated by `tools/make_wallpapers.py`) |
| `crates/tvs-deploy` | Deployment profile, dry-run planner, journaled runner with reconnect and resume |
| `crates/tvs-insight` | Home-screen benchmark with cautious before/after verdicts, evidence-graded privacy audit |
| `crates/tvs-demo` | Simulated TCL Google TV for demo mode and the end-to-end tests |
| `crates/tvs-store` | SQLite: settings, devices, write-once baselines, versioned profiles, journal |
| `docs/` | Research, spec, architecture, capability matrix, plan |

## Develop (Windows)

Prerequisites: Rust stable (MSVC), Node 22, pnpm 10, Visual Studio Build Tools ("Desktop development with C++"), WebView2 (preinstalled on Windows 11).

```powershell
cd C:\dev\tv-studio
pnpm install
pnpm tauri dev          # run the app
pnpm test               # UI tests
cargo test --workspace  # core tests
pnpm tauri build        # NSIS installer + target\release\tv-studio.exe
```

### Try it without a TV

Settings → Demo → "Practice on a simulated TV" (or start with `$env:TVS_DEMO = "1"; pnpm tauri dev`). Every screen
then works against a built-in simulated TCL Google TV: connect to `192.168.1.50` (pairing code `123456`). Nothing
real is changed, and a yellow banner says so on every screen.

### Launcher APK (for local builds)

```powershell
cd C:\dev\tv-studio\launcher
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"   # Android Studio's JDK 17+
.\gradlew.bat --no-daemon testReleaseUnitTest assembleRelease
copy app\build\outputs\apk\release\app-release.apk ..\src-tauri\resources\launcher\studio-home.apk
```
Official builds get it from CI automatically. Without it the app still works; the launcher features say it isn't bundled.

Until adb is bundled, the app uses `adb.exe` from your Android SDK (`%LOCALAPPDATA%\Android\Sdk\platform-tools`),
from `PATH`, or from the path set in Settings.
